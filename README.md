# Flight Path

<p align="center">
  <img src="./readme/camera_tracking.png" alt="Camera Tracking">
</p>

Flight Path is a modular, Python-based visual odometry project that combines state-of-the-art deep learning techniques with classical geometry. It integrates RAFT-based optical flow and stereo disparity methods with SVD-based camera pose estimation (via the Kabsch algorithm). My little R&D in autonomous navigation and computer vision.
